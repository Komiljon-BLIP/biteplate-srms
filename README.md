# BitePlate Smart Restaurant Management System

## Overview

BitePlate SRMS is a Modular Monolith Restaurant Management System 
developed using enterprise software engineering principles.

## Technology Stack

- Java 21
- Spring Boot
- PostgreSQL
- RabbitMQ
- Maven
- REST API
- Modular Monolith Architecture

## Features

- Reservation Management
- Table Management
- Order Management
- Kitchen Queue
- Billing & POS
- Staff Management
- Order History
- High-Concurrency Reservation Processing

## Architecture

- Layered Architecture
- Event-Driven Communication
- Queue-Based Reservation Processing

## Documentation

See the `docs` folder.
